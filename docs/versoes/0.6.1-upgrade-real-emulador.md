# Flow Programação Guiada — validação de atualização 0.6.0 → 0.6.1

Criador: Ander Flow. Esta alteração acrescenta teste de atualização real entre duas versões compiladas no mesmo runner GitHub Actions.

## Cenário reproduzido

O teste anterior reinstalava o mesmo APK 0.6.1. Isso não comprovava que uma atualização de `versionCode=6` para `versionCode=7` preservava dados.

## Novo gate

1. Compilar o código anterior 0.6.0 em diretório isolado e o código 0.6.1 no mesmo runner.
2. Verificar pacote `br.com.ander.flow`, progressão estrita de `versionCode` e certificado SHA-256 idêntico nos dois APKs.
3. Instalar o APK anterior no emulador Android 15, escrever marcador privado com `run-as`, atualizar com `adb install -r`, confirmar marcador preservado.
4. Conferir versão instalada, abertura da MainActivity, processo ativo, captura e ausência de exceção fatal.
5. Publicar evidências nos artefatos temporários do CI, sem promover APK debug a release.

## Segurança e limites

- O teste não executa `adb uninstall`, `pm clear` nem altera dados de um dispositivo físico.
- A chave de depuração gerada no runner é efêmera. Igualdade entre as duas compilações **não prova** compatibilidade com assinatura já instalada no Galaxy A35.
- Não promover APK de CI ao Drive como instalável sem confirmação de assinatura, proveniência, versão e gates.
- Versões anteriores do Drive não são sobrescritas.
